# Scripts that pass or fail on a captured screen

Use with step 4 of `../SKILL.md` when a script's verdict comes from the screen text: a live check, a smoke test, a CI step. Besides the app, the screen can show help text such as "Nothing runs…" or a box the host draws.

- **Own the socket.** Before starting, refuse a socket that already has sessions (`tmux -L <name> list-sessions` exits 0). End only your own session with `kill-session -t =<session>`; tmux exits once its last session is gone, and `kill-server` would end every other session on that socket too. `tui.mjs start` refuses an occupied socket, and its `stop` ends only the session it names, so a cleanup trap after a refused start is safe.
- **Pass the command as argv.** Give tmux the command and each argument as separate entries after the options, with `env` first: `spawn('tmux', ['-L', sock, 'new-session', '-d', '-s', session, 'env', cmd, ...args])`. tmux runs a lone entry, and any shell string, through `sh -c`, so a quote or `$` in an interpolated path runs as code.
- **A ready-wait timeout is a setup error.** Print the screen and exit 2, distinct from a failed check (exit 1): a check run on a screen where the app never opened reports on the shell, not the app.
- **Locate the app's region by its frame, then check only inside it.** Find the border characters that enclose the app (box corners, border runs) and cut the lines and columns to that region. Run every check there, patterns the user passes in (`--expect`) included. No frame found is a setup error. The frames of Claude Code panes are in [claude-code.md](claude-code.md).
- **Count terminal cells, not characters.** East Asian Wide and Fullwidth characters and emoji such as ✅ and ⏰ take 2 cells; combining and zero-width marks take 0. A UTF-8 locale does not change this. Indexing with `line.length` or `Array.from(line)` shifts every column right of a wide character, so a frame's top and bottom corners no longer line up. `node "$T" find` prints cell columns.
- **Keep one negative fixture per spoof.** Put a fake `tmux` first on `PATH` that prints a canned screen: the expected text only in the transcript, a quoted label, a second box outside the app. Assert the script fails on each; a spoof without a fixture comes back with the next change.
- **Write down the residual limits and stop.** Name in the script's usage what it cannot tell apart (for example, a transcript that draws an exact copy of the frame). Adding a heuristic per new spoof makes the check harder to read than the app.
