# dash: features

1. Band: one line above the prompt with counts of running agents, shells, monitors and crons, and the session cost.
2. Items tab: every background item grouped by kind; the detail follows the focus.
3. Cost tab: estimated dollars per agent, from token counts and list prices.
4. Timeline tab: one bar per item from start to end, with who started it.
5. Workflows: multi-phase agent runs shown with their phases.
